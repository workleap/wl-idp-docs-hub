# wl-idp-docs-hub

## Installation

This project uses [pnpm](https://pnpm.io/installation) 12. pnpm downloads the version pinned in the `packageManager` field of [package.json](./package.json) by itself.

## Usage

```bash
pnpm install
pnpm dev
```
